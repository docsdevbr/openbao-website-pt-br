# Habilite a coleta de telemetria do OpenBao

Colete dados de telemetria da sua instalação do OpenBao.

## Antes de começar

- **Você precisa ter acesso ao seu
  [arquivo de configuração do OpenBao](../../configuration/index.mdx)**.

## Passo 1: Escolha um agente de agregação

@include 'telemetry/supported-aggregation-agents.mdx'

## Passo 2: Habilite pelo menos um dispositivo de auditoria

Para incluir métricas relacionadas à auditoria, você precisa habilitar a
auditoria em pelo menos um dispositivo com o comando `bao audit enable`.
Por exemplo, para habilitar a auditoria para o dispositivo `file` e salvar os
logs em `/var/log/openbao_audit.log`:

```shell-session
$ bao audit enable file file_path=/var/log/openbao_audit.log
```

## Passo 3: Configure a coleta de telemetria

Para configurar a coleta de telemetria, atualize a seção de telemetria na sua
configuração do OpenBao com suas preferências de coleta e detalhes do agente de
agregação.

Por exemplo, a seguinte stanza `telemetry` configura o OpenBao com as
configurações padrão de telemetria e o conecta a um agente Statsite em execução
na porta padrão dentro da intranet de uma empresa em `minhaempresa.statsite`:

```hcl
telemetry {
  usage_gauge_period = "10m"
  maximum_gauge_cardinality = 500
  disable_hostname = false
  enable_hostname_label = false
  lease_metrics_epsilon = "1h"
  num_lease_metrics_buckets = 168
  add_lease_metrics_namespace_labels = false
  filter_default = true

  statsite_address = "minhaempresa.statsite:8125"
}
```

Muitas soluções de métricas cobram por métrica.
Você pode definir `filter_default` como false e usar o parâmetro `prefix_filter`
para incluir e excluir valores específicos com base no nome da métrica para
evitar pagar por informações irrelevantes.

Por exemplo, para limitar sua telemetria às métricas principais do token mais o
número de concessões com vencimento definido:

```hcl
telemetry {
  filter_default = false
  prefix_filter = ["+vault.token", "-vault.expire", "+vault.expire.num_leases"]
}
```

## Passo 4: Escolha uma solução de relatório

Você precisa salvar ou encaminhar seus dados de telemetria para uma solução de
armazenamento separada para geração de relatórios, análise e alertas.
A solução necessária depende do conjunto de recursos fornecido pelo seu agente
de agregação e do suporte a protocolos da sua plataforma de relatórios.

Soluções populares de geração de relatórios compatíveis com o OpenBao:

- [Grafana](https://grafana.com/grafana)
- [Graphite](https://www.hostedgraphite.com)
- [InfluxData: Telegraf](https://www.influxdata.com/time-series-platform/telegraf)
- [InfluxData: InfluxDB](https://www.influxdata.com/products/influxdb-overview)
- [InfluxData: Chronograf](https://www.influxdata.com/time-series-platform/telegraf)
- [InfluxData: Kapacitor](https://www.influxdata.com/time-series-platform/kapacitor)
- [Splunk](https://www.splunk.com)
