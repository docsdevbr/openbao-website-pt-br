# Visão geral das métricas de telemetria

## Tipos de métricas

O OpenBao oferece três tipos de métricas de telemetria:

- **Métricas de counter** incrementam quando um evento ocorre.
  Os counters são cumulativos e reiniciados ao final dos intervalos de
  relatório.
- **Métricas de gauge** fornecem medições dos valores atuais.
- **Métricas de summary** fornecem valores observacionais.
  O OpenBao geralmente usa summaries para medir o tempo necessário para que um
  evento discreto seja concluído.

Gauges de alta cardinalidade, como `vault.kv.secret.count`, são atualizados no
intervalo configurado com `usage_gauge_period` na stanza `telemetry`.
O intervalo de relatório padrão para métricas de gauge é de 10 minutos.

## Rótulos de métricas

Algumas métricas de telemetria vêm com metadados adicionais que fornecem
contexto para a medição.
Por exemplo, uma métrica de token pode incluir o namespace ao qual pertence ou o
método de autenticação usado para criá-la.

Os metadados da métrica são rotulados e incorporados ao nome da métrica para a
telemetria em memória e qualquer outro mecanismo de telemetria que não suporte
rótulos personalizados.

O nome da métrica na tabela abaixo é seguido por uma lista de rótulos
suportados, na ordem em que aparecem, se simplificados.


| Rótulo                 | Exemplo                   | Descrição                                                                                                                                         |
|------------------------|---------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------|
| `auth_method`          | `userpass`                | Tipo de mecanismo de autorização.                                                                                                                 |
| `cluster`              | `openbao-cluster-d54ad07` | Nome do cluster de origem da métrica.                                                                                                             |
| `creation_ttl`         | `7d`                      | Tempo de vida atribuído na criação, arredondado para o próximo bucket superior: `1m`, `10m`, `20m`, `1h`, `2h`, `1d`, `2d`, `7d`, `30d` ou `+Inf` |
| `mount_point`          | `auth/userpass/`          | Caminho no qual um método de autenticação ou mecanismo de segredos está montado.                                                                  |
| `name`                 | `memoryLimit`             | Nome do objeto que está sendo agregado (por exemplo, uma cota ou regra de cota).                                                                  |
| `namespace`            | `ns1`                     | Um caminho de namespace ou `root` para o namespace raiz.                                                                                          |
| `policy`               | `default`                 | Nome da política associada.                                                                                                                       |
| `secret_engine`        | `kv`                      | Tipo de mecanismo de segredos.                                                                                                                    |
| `token_type`           | `service`                 | Tipo do token associado: `batch` ou `service`.                                                                                                    |
| `peer_id`              | `node-1`                  | Identificador único de um nó par do raft.                                                                                                         |
| `node_id`              | `node-42`                 | Identificador único de um nó par do raft (duplica `peer_id`).                                                                                     |
| `snapshot_config_name` | `config1`                 | Nome da configuração usada para snapshots automatizados.                                                                                          |
